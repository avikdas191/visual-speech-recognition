# Data



This folder is empty in the public repository. The datasets are too large to
distribute, and the source recordings are of a single speaker and are not
published.

## What belongs here

`lip_images/` holds the assembled grid-image datasets.

`7_final_images_130` is the dataset from the original project, on which the
deployed model reached 98.50%. The name refers to its 130 images per word:
images 001 to 060 are the real recording sessions and 061 to 130 are augmented
images generated from them. It is kept because the comparison between it and
the rebuilt dataset is the most instructive result in the project. Its split
was made by image index after augmentation had been applied, so a test image
could be a transformed copy of a recording the model trained on. See
`docs/results_comparison.md`.

`06_dataset_final` is the rebuilt dataset that the reported results come from:
90 training, 20 validation and 20 test images per word, split by recording
session before augmentation so that no augmented image derives from a session
in another split. `06_test_real_only` holds the 9 unaugmented test images per
word, which give the 75.56% figure.

`text_corpus/` holds the sentence data used to fine-tune the sentence
generation model. `1_raw_data/` contains one file per word, and `dataset.csv`
is the assembled input and target pairs.

## Reproducing it

Every dataset here is generated by the notebooks in `src/data_prep/` from the
original video recordings: 600 videos of one speaker, ten words, sixty
recording sessions. Those recordings are not published.

The generation process is documented in full. See
`docs/results_rebuilt_data/` for how each stage works, from frame extraction
through lip cropping and augmentation to grid assembly, and
`docs/text_corpus_construction/` for the sentence data. The comparison between
the two lip-image datasets is in `docs/results_comparison.md`.
